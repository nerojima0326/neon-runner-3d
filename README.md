# Neon Runner 3D

### ▶ [바로 플레이: nerojima0326.github.io/neon-runner-3d](https://nerojima0326.github.io/neon-runner-3d/)

네온 신스웨이브 세계를 질주하는 3D 러너 게임. 순수 HTML/CSS/JS + Three.js, 빌드 도구·서버 프레임워크 없이 **정적 파일만으로** 동작합니다.

## 실행

| 방법 | 설명 |
|---|---|
| `start.bat` 더블클릭 | Windows 기본 PowerShell로 `http://localhost:8080` 서버를 띄우고 브라우저를 엽니다 |
| 아무 정적 호스팅 | 폴더 전체를 업로드하면 끝 (GitHub Pages, Netlify, Vercel, itch.io, Cloudflare Pages 등) |

> `index.html`을 더블클릭(file://)으로 열면 ES 모듈 보안 정책 때문에 동작하지 않습니다. 반드시 http(s)로 서빙하세요.

## 시스템

- **장애물 4종**: 빨간 레이저(점프) · 노란 게이트(구르기) · 크리스탈(피하기, 더블 점프 가능) · 플라즈마 오브(좌우 이동)
- **첫 판 연습 구간**: 처음 플레이하면 120m 동안 느린 속도로 장애물이 한 개씩 점프 → 구르기 → 피하기 순서로 등장 (초보자 힌트 설정이 켜져 있을 때)
- **존 시스템**: 500m마다 SYNTHWAVE → INFERNO → TOXIC → AURORA. 존마다 색과 장애물 비중이 다름
- **점수**: 거리 + 코인(50 × 콤보 배율) + 보너스(대시 파괴 100, 아슬아슬 회피 25)
- **콤보**: 4초 안에 코인을 계속 먹으면 콤보 유지, 10개마다 배율 +1 (최대 ×5)
- **아슬아슬 회피(Close Call)**: 마지막 순간에 레인을 바꾸거나 간신히 넘으면 보너스 + 에너지
- **아이템 4종**: 🛡 방어막(한 번 막아줌) · 🧲 자석(10초 코인 흡수) · ⏱ 슬로우모(실시간 5초 동안 게임 속도 0.55배, 점프 궤적·간격은 그대로) · ✨ 점수 2배(10초, 코인·보너스 점수)
- **영구 업그레이드 5종**: 샵에서 코인으로 자석 지속·대시 지속·에너지 충전 속도·컨티뉴 할인·시작 방어막 강화 (전부 사면 약 15,000 코인)
- **컨티뉴**: 한 판에 한 번, 코인 100개(업그레이드로 최대 40까지 할인)로 그 자리에서 부활 (5초 카운트다운)
- **데일리 챌린지**: 날짜 시드 난수 → 전 세계 모두 같은 코스. 매일 변형 규칙(더블 코인, 터보 스타트, 장애물 밀집, 아이템 금지, 자석 스타트, 저중력, 슬로우 스타트)이 바뀜. 별도 랭킹
- **데일리 고스트**: 오늘 최고 기록 주행을 0.5m 단위로 기록해 다음 도전에서 2m 앞에 반투명 캐릭터로 재생. 최고 기록이 끝난 지점에서 터지며 "최고 기록 돌파" (설정에서 끌 수 있음, 날짜가 바뀌면 자동 삭제, 3,000m ≈ 16KB)
- **보스전** (`js/boss.js`): 5,000점에서 첫 보스, 끝날 때마다 +12,000점에서 다음 보스(NEON SENTINEL → CRIMSON OVERLORD → VOID MONARCH → MK-2…). 진입 순간 트랙 위 장애물이 전부 터지며 사라지고, 카메라가 플레이어 옆을 돌아 **앞쪽에서 플레이어 얼굴과 뒤에서 쫓아오는 보스를 함께** 비춤(이때 좌우 조작은 화면 기준으로 뒤집힘). 보스전 동안 일반 장애물은 나오지 않고, 공격은 전부 뒤(보스 쪽)에서 다가옴: ① 레인 레이저(바닥 경고 줄무늬 → 레인 전체 빔, 옆 레인으로 피함) ② 폭탄(플레이어 뒤에 떨어져 굴러옴, 점프나 레인 변경으로 피함) ③ 장애물 소환(뒤에서 덮쳐오는 빨간 레이저·노란 게이트·크리스탈). 뒤에서 다가오는 🔵 파란 오브를 먹으면 유도탄이 날아가 HP 1 감소. 75초 안에 못 잡으면 도망감. 레벨이 오를수록 HP·공격 빈도 증가, 레벨 2+는 HP 절반 이하에서 레이저 2줄, 레벨 3+는 폭탄 2개. 대시 중엔 폭탄을 부수고 레이저를 통과, 방어막은 공격 1회를 막음. 격파·도주 연출이 끝나면 카메라가 다시 뒤로 돌아오고 일반 장애물이 재개됨. 격파 보상 점수 3,000 × 레벨 · 코인 40 × 레벨
- **미션**: 3개씩 활성, 완료 시 코인 보상. 16개를 다 깨면 **판이 끝난 뒤** 티어 상승(목표치 1.5배)
- **업적 18종**: 영구 뱃지, 달성 시 상단 토스트
- **스킨 샵 6종**: 코인으로 구매(고스트=와이어프레임, 프리즘=무지개 순환)
- **랭킹**: 클래식 top 10 · 오늘의 데일리 top 10 · (선택) 온라인 클래식 · 온라인 데일리
- **통계**: 메인 메뉴에 플레이 횟수 · 누적 거리 · 누적 코인
- **설정**: 이름, 밝기(노출), 그래픽 품질(자동/낮음/중간/높음), 효과음, 음악, 화면 흔들림, 초보자 힌트, 진동(모바일), 고대비 장애물, 데일리 고스트
- **접근성**: OS의 "움직임 줄이기"가 켜져 있으면 흔들림이 기본 꺼지고 배너·토스트 애니메이션이 페이드로 단순화. 고대비 모드는 장애물을 파랑/노랑/흰색/주황으로 바꿔 적록색약도 구분 가능
- **PWA**: 홈 화면 설치, 한 번 실행 후 오프라인 플레이 (`manifest.json`, `sw.js`)
- **공유**: Web Share API(모바일) 또는 클립보드 복사
- **BGM/효과음**: 외부 파일 없이 WebAudio로 실시간 합성 (용량 0, 속도에 따라 강도 변화)
- **충돌 이펙트**: 대시 파괴·방어막 파괴·사망마다 장애물 색 파편(바닥에 튕김) · 불꽃 줄기 · 바닥 충격파 링 · 섬광 · 순간 조명 · 히트스톱 · 화면 가장자리 색 섬광. 아슬아슬 회피는 장애물 가장자리에서 초록 불꽃. 파편·불꽃은 InstancedMesh 1드로우콜씩 (`js/fx.js`의 `impact`)
- **플레이어·획득 이펙트** (`js/vfx.js`): 코인(팝 링 + 콤보 배율 색 별) · 점프 먼지 고리 · 더블 점프 공중 링 · 착지 충격 고리 · 구르기 바닥 불꽃 자국 · 대시 시작 금빛 링 · 콤보 상승 링 · 방어막(육각 에너지막 셰이더 + 스캔 띠, 켜질 때 탄성 팽창) · 자석(자이로 고리 + 빨려드는 자기장 파동 + 끌려오는 코인 꼬리) · 점수 2배 금빛 반짝이 · 슬로우모 시간 파문
- **플라즈마 오브**: 소용돌이 플라즈마 셰이더 핵 · 후광 · 전자 궤도 고리 3개 · 번개 · 이동 잔상 · 바닥 이동 경로 표시
- **장애물 연출**: 바닥 네온 빛 웅덩이 + 멀리서 바닥에서 솟아오르며 등장
- **보스 모델 (보스마다 다름)**: NEON SENTINEL = 사자 머리, CRIMSON OVERLORD = 황소 머리(받침대는 로딩 때 잘라냄), VOID MONARCH = 해골. 전부 CC0 glTF. 원래 재질 대신 어두운 금속 + 보스 색 네온 테두리(프레넬) 재질을 입히고(.gltf는 노멀맵만 받아 표면 결 유지), 눈에서 보스 색 빛이 깜빡이며 고개를 돌려 플레이어를 따라봄. 레이저·폭탄은 입에서 발사. 눈·입 위치는 [가로, 세로] 비율로 지정하면 앞에서 광선을 쏴 얼굴 표면에 자동으로 붙음. 첫 보스 모델은 캐릭터 로딩 뒤 백그라운드로, 다음 보스 모델은 앞 보스 등장 때 미리 받음. 못 받았거나 오프라인 첫 실행이면 절차 생성 보스(구체 + 눈)로 싸우고 도착 즉시 교체. 설정은 `js/config.js`의 `BOSS.MODELS`
- **보스 그로기**: 파란 오브 유도탄에 맞으면 `BOSS.STUN_TIME`(2.2초) 동안 공격을 멈추고(경고 중이던 레이저도 취소) 헤롱헤롱: 머리 위로 노란 별 5개가 빙빙 돌고, 눈이 소용돌이(@_@)로 바뀌고, 고개가 휘청이며 몸이 내려앉아 8자로 비틀거림. 고리·파편도 느려지고 처짐. HP 바에 `💫 STUN` 표시. 다시 맞으면 그로기 시간이 처음부터
- **캐릭터 모델**: glTF 로봇 "RobotExpressive"(three.js 예제 동봉, 464KB)를 CDN에서 로드해 달리기·점프·대기·손흔들기 스켈레톤 애니메이션 재생. 구르기·대시 중에는 공으로 변신(절차 생성 구체). 모델 로딩에 실패하거나 오프라인 첫 실행이면 구체 캐릭터로 자동 폴백. 스킨은 두 모델 모두에 적용(몸 색 → 로봇 Main, 팔다리 색 → Grey, 고스트=와이어프레임, 프리즘=무지개). 모델 주소·크기·클립 이름은 `js/config.js`의 `CHARACTER`

## 최적화

- 파티클 600개 → `InstancedMesh` 1 드로우콜, 볼라드 80개 → `InstancedMesh` 1 드로우콜
- 도시 빌딩 135개 → 지오메트리 병합으로 2 드로우콜
- 장애물·코인·잔상 **오브젝트 풀링** (게임 중 GC 압력 없음)
- 매 프레임 벡터/문자열 생성 없음, DOM은 값이 바뀔 때만 갱신
- **스윕 충돌 판정**: 프레임이 느려도 장애물이 플레이어를 통과(터널링)하지 않음
- 자동 품질: 3초 평균 프레임이 느리면 그림자 → 블룸 순으로 끔. 내려간 단계는 기억해 다음 실행부터 바로 적용 (터치 기기는 중간부터 시작)
- 탭이 가려지면 자동 일시정지 + 오디오 정지 + 컨티뉴 카운트다운 정지, 최소화 시 0×0 리사이즈로 버퍼가 깨지는 문제 방지
- 데일리 코스 셔플은 Fisher-Yates (엔진마다 결과가 다른 `sort(랜덤)` 사용 안 함)

## 수익화 연결 지점 (직접 붙여야 하는 부분)

이 프로젝트는 **광고/결제/서버 없이** 완전히 동작하는 상태입니다. 실제 수익을 내려면 아래 지점에 SDK를 붙이면 됩니다.

| 지점 | 파일 / 함수 | 붙일 것 |
|---|---|---|
| 부활 | `js/main.js` → `die()`에서 `ui.showContinue(...)` 호출 직전 | **보상형 광고**: "광고 보고 무료 부활" 버튼. 광고 완료 콜백에서 `revive()` 호출 (코인 차감 없이) |
| 결과 화면 | `finishRun()` 끝 | **보상형 광고**: "광고 보고 코인 2배" → `profile.bank += bankGain` |
| 샵 | `ui.bind({ buy })` | **인앱 결제**: 코인 팩 판매 → `profile.bank += n; save()` |
| 판 사이 | `openMenu()` | **전면 광고**: N판마다 1회 (너무 자주 띄우면 이탈률 급등) |
| 데일리 | `openDaily()` | 데일리 재도전권(광고) 등 |

플랫폼별 SDK 예: 웹 → Google AdSense H5 Games Ads / Poki / CrazyGames SDK, 앱 포장 → Capacitor + AdMob.

## 온라인 랭킹 (선택)

`js/config.js`의 `ONLINE_LEADERBOARD_URL`에 서버 주소를 넣으면 자동으로 점수를 전송하고 랭킹 탭에 "온라인"·"온라인 데일리"가 생깁니다. 점수는 결과 화면에서 이름 입력을 마치고 나갈 때 전송됩니다(탭을 닫아도 keepalive로 전송). 서버 규격:

```
POST {URL}            body: { board: "classic"|"daily", date: "YYYY-MM-DD", name, score, dist, zone }
GET  {URL}?board=classic|daily&date=YYYY-MM-DD   →  [{ name, score, dist, zone, date }, ...]  (점수 내림차순, 최대 50)
```

**바로 쓸 수 있는 서버**: `server/worker.js` (Cloudflare Workers + KV, 무료 플랜으로 충분). 파일 상단의 배포 순서를 따르면 3분 안에 올라갑니다. 점수 상한·이름 길이·거리 대비 점수 비율 검증이 들어 있습니다. Firebase, Supabase 등으로 옮겨도 같은 규격이면 됩니다.

## 버전 올리기

`js/config.js`의 `VERSION`만 올리면 됩니다. 서비스워커는 `sw.js?v=VERSION`으로 등록되므로 캐시 이름이 자동으로 바뀌고 구버전 캐시는 삭제됩니다.

## 디버그

`?debug=1`을 붙여 열면 콘솔에 `NR` 객체가 생깁니다: `NR.energy()`, `NR.dash()`, `NR.spawn('wall', 1)`, `NR.item('slow')`(shield/magnet/slow/boost), `NR.coins(1000)`, `NR.boss()`(점수와 상관없이 다음 보스 즉시 소환, `NR.boss(3)`처럼 레벨 지정 가능), `NR.die()`, `NR.profile`, `NR.ghost`, `NR.step(60)`(탭이 가려져 프레임이 안 돌 때 시뮬레이션 n프레임 강제 진행) 등.

## 밸런스 조정

대부분 `js/config.js`만 바꾸면 됩니다: 속도·중력·점프력(`PHYS`), 가속(`ACCEL`: 현재 속도에 비례, 0.15면 최고 속도까지 약 2분 30초), 장애물 줄 간격(`ROW_SEC_START`·`ROW_SEC_MAX`: 시작/최고 속도에서 줄 사이 초), 존별 장애물 비중(`THEMES[].weights`), 아이템 비중(`ITEM_WEIGHTS`), 슬로우모·점수 2배 지속(`SLOW_TIME`·`SLOW_FACTOR`·`BOOST_TIME`), 업그레이드 가격/효과(`UPGRADES`), 스킨 가격, 미션 목표/보상, 컨티뉴 비용(`REVIVE_COST`), 콤보 규칙, 보스전(`BOSS`: 등장 점수·HP·제한 시간·공격 간격·레이저/폭탄 타이밍·보상·카메라).
